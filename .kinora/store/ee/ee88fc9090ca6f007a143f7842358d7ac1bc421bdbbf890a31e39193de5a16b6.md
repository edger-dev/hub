# Plan — M4: run the mesh over real TCP

**Task:** kino://bc55e080ca2379cbae9a54e9948df146285713cc63ce4c164d8b81fd7848f470

Transport at both ends, then prove it on a real socket, then make it runnable.

## Phase 1 — the hub accepts over TCP

- `hub::serve_tcp(hub, addr)`: bind a `TcpListener`, accept forever, spawn
  `serve_connection` per connection so peers are independent.
- Return the bound address so a test can use port 0 and learn the real port.
- Test: two connections are served concurrently; dropping one leaves the other
  registered.

*Status:* **done** (commit 45e8c25) — HubListener::bind/local_addr/serve; each
connection runs in a JoinSet owned by the serving future, and a LiveConnections
guard shuts live handles down on drop so stopping the hub doesn't strand peers.

## Phase 2 — the node dials TCP

- Parse `HubEndpoint` (`tcp://host:port`, or bare `host:port`) into a dial
  target; a malformed address is a config error, not a panic.
- `node::dial_tcp(endpoint)`: connect and hand back a link for
  `serve_and_register`; a refused connection is `None` so the reconnect loop
  treats a down hub as a retry, not a failure (§2.1).
- Test: dialing a closed port yields no link rather than an error.

*Status:* **done** (commit 45e8c25) — HubEndpoint::dial_target accepts
tcp://host:port or bare host:port and rejects other schemes as a config error;
node::tcp::dial yields None for an unreachable hub. 4 unit tests.

## Phase 3 — end-to-end on a real socket

- Node registers with a TCP hub; a consumer sees it in `topology` and routes a
  call to it.
- **The reconnect proof:** stop the hub, restart it on the same port, and assert
  the node re-registers on its own (§2.1 — "the hub blinked").

*Status:* **done** (commit 45e8c25). over_tcp.rs proves register → discovery →
routed call on a real socket. The restart proof needed a **process** boundary:
in-process, neither dropping nor shutdown()-ing a vox connection closes its
socket, so a peer never observes the hub going away
(kino://0092dc47d183a6e1ec3e2185990f5e8904023dfe3e8057cc16b95fd7a6f33522).
restart.rs therefore spawns the real hub binary, kills it, restarts it on the
same port, and asserts the node re-registers unaided.

## Phase 4 — binaries, then close out

- `hub` bin: address from arg/env, serve until killed.
- `node` bin: node id, link label, and hub address from arg/env; run the
  reconnect loop.
- Zero warnings; review; `// implements:` refs; mark task + plan resolved.

*Status:* **done** — both bins build and were run by hand end to end (the node
logs "hub connection closed; re-dialing" the instant the hub is killed).
49 tests green workspace-wide; clippy --deny warnings clean.
