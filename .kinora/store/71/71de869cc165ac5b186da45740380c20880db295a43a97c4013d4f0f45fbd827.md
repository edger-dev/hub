# Task — M2: the node daemon stub

**Goal.** A `crates/node` daemon skeleton that behaves like a real node at the
protocol edge — it **reverse-dials** the hub, **serves** `NodeService`, and
**registers** — but stubs out the actual connector behaviour. It is the first
consumer of the M1 `hub-protocol` contract and proves the reverse-dial shape end
to end against a fake hub, with no real hub implementation needed yet.

**Correction (M3).** This task originally recorded that vox "folds a method's
domain `Result` into the call error, so `register`'s `HubError` arrives as text".
That was wrong: the generated client returns `Result<T, VoxError<E>>` and the
callee's error is carried structurally in `VoxError::User(E)`. `serve_and_register`
now recovers the typed `HubError` (`DialError::Rejected`). See
kino://1d03e8efe327479dcd8c33b0c71a56c43677147e43d6a0105616844a79f7e92d.
