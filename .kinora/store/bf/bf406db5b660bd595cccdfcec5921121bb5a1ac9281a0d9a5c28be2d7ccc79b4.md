# Spec — uniform node addressing by registry name

**Contract.** A node is addressed exactly one way: by its `NodeId` — its name in
the hub's registry. There is no node-local listener and no per-node endpoint to
discover; a node reaches consumers only as a hub provider (it reverse-dials in).

**Chosen.** `NodeId` (a registry name) as the sole address, stable across a
node's links and across daemon restarts. Two daemons for one node are told apart
by a `LinkLabel`, never by listen address.

**Rejected.** Keeping a node-local direct path alongside the hub. It is dead
weight once a co-located agent goes through the local hub uniformly, and it
reintroduces an `EADDRINUSE` crash-loop footgun when a second daemon binds the
same port. Also rejected: idling when no hub is set — the hub is mandatory
infrastructure, so a missing hub is a hard startup error.

**Escape hatch.** A solo setup collapses to one hub (dev == stable); addressing
and routing behave identically with a single hub.
