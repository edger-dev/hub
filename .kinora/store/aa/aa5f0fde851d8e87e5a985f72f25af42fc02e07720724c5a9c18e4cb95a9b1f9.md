# Task — M5: real connectors behind `deliver`

**Goal.** Replace the node's blanket refusal with real **connector dispatch**:
a registry of connectors, addressed by id, each owning its own payload codec —
plus one reference connector so the mesh finally *does* something end to end.

**Realizes:**

- kino://d78fb95fddc31aa42bc927da1eaed44292529b3671d1ef9ef58ec8cd0858e51c —
  a connector owns its payload; the hub never inspects it (§1).
- kino://08c3ce357742ccf578caddcfb6578a92216b515adcfe1ac9de4543406be52cb0 —
  `start`-type work is link-scoped; reads are link-agnostic (§2.5).

**Plan:** kino://f62ec644928c2a7294ddc51e30522a7670a8b1d50044b60002a20a9a7a2d7d3a

**Done when:**

- A `Connector` trait the node dispatches to by id, with an unknown id still
  answering `NodeError::UnknownConnector` and an unknown method a clear refusal.
- The node advertises its registered connectors in `Registration`, so discovery
  reports what a link can actually do (§2.6).
- A reference **files** connector (list/read under a configured root) proves the
  path, including that it refuses to escape its root.
- End-to-end: a consumer routes a files call through the hub to the node and
  gets real content back.
- The `node` binary registers the reference connector when configured to.
- Zero warnings; committed; task + plan resolved.

**Out of scope:** process/session connectors and the job substrate (a separate
brief), auth/ACLs on connector calls, the console, the event store, packaging.

---

**Resolved.** The node dispatches routed calls to registered connectors, each
owning its payload codec, and advertises them so discovery reports what a link
can really do. The reference `files` connector (list/read, rooted, read-only)
proves the path end to end through the hub, and refuses to be talked out of its
root — lexically and after canonicalisation, so a symlink cannot escape either.
63 tests green; clippy clean; verified with the real binaries
(`NODE_FILES_ROOT` registers the connector).

Carried forward: process/session/command connectors and the job substrate (a
separate brief), per-connector auth/ACLs — today any consumer that reaches the
hub can call any connector — and streaming payloads (a call is one request and
one reply; a `Tx` in a connector method would need protocol support).
