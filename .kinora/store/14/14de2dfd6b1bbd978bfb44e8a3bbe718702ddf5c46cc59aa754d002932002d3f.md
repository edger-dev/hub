# Spec — the hub is a stable protocol boundary

**Contract.** Every role (node, consumer, the hub itself) binds to a single,
published protocol surface — the vox service traits and facet message types in
`hub-protocol` — and to *nothing behind it*. No client may reach a node's local
endpoint or the event store's API directly.

**Chosen.** One versioned wire contract (`HubService` + `NodeService` + the
message types) as the only coupling point. Implementations behind it — the event
store, the connector set, which node hosts what — change without a client edit.

**Rejected.** Clients binding to a store API or a node-local endpoint. That welds
callers to details the design means to keep swappable; every store swap or
topology change would ripple into clients.

**Escape hatch.** Evolve the contract by versioning the protocol crate, not by
letting a client reach around it. A capability the protocol cannot yet express
rides `RoutedCall`'s opaque payload until it earns a first-class method.
