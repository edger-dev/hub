# Task — M1: the hub protocol API surface

**Goal.** Define the hub's **stable protocol boundary** as a standalone crate
(`crates/hub-protocol`): the vox service traits every role dials, plus the facet
message + identity types they exchange. This is the seam the whole design leans on
— "the hub presents a stable protocol; what is behind it is swappable." No hub or
node *implementation* behind it yet; just the contract, compiling and tested.

**Realizes** (carved from the design brief kino://dd44162bff0f6e6095fe037b45c6de507bcff05f26e2caa18594937d27b9a1c9):

- §1 — the stable protocol boundary; clients bind to the protocol, never to a
  store API or a node's local endpoint.
- §2.1 — nodes reverse-dial; registration/heartbeat shape reflects out-dialing.
- §2.4 — hub-only, uniform addressing: a node is reached by its **name** in the
  registry, never a local endpoint.
- §2.5 — one node, many **links** (`stable`/`dev`); a request targets node +
  optional link label; reads are link-agnostic, `start` is link-scoped.
- §2.6 — live node discovery derived from the reverse-dial registry (topology
  snapshot + live tail), not a static list.
