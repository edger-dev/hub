## Phase 2 — facet message + identity types (TDD)

Types the brief implies, smallest set that carries M1:

- **Identity:** `NodeId` (registry name — §2.4), `LinkLabel` (`stable`/`dev` +
  custom — §2.5), `NodeLink` (node + link).
- **Registration:** what a reverse-dialing link announces — node id, link label,
  offered connectors, agent/version metadata (§2.1, §2.4).
- **Connector:** a descriptor identifying a connector a link offers (process mgmt,
  sessions, files, commands — §1). Kind + id, not the impl.
- **Discovery:** `NodeInfo` / `TopologySnapshot` — live connected nodes, their
  links and connectors (§2.6).
- **Targeting:** `LinkSelector` — node + optional link label, encoding
  default-to-stable / fall-back-to-stable routing (§2.5).

Tests first: facet serialize → deserialize round-trip + shape assertions.

*Status:* **done** — all five modules landed (commit dcb1b21); 11 round-trip/shape tests green; clippy --deny warnings clean. NodeId/LinkLabel/NodeLink, Connector/ConnectorKind, Registration, LinkInfo/NodeInfo/TopologySnapshot, LinkSelector.
